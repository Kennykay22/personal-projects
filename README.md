## AI projects

- **[ORBIT — Space Observatory](ai-projects/orbit/):** an interactive space website with black-hole experiments, a Universe atelier, planetary exploration, satellite networks, orbital mechanics, gravity experiments, and expedition tools. Developed with AI assistance using OpenAI Codex.
  - [Live website](https://orbit-atlas-nasa-explorer.longalbum.chatgpt.site/)

## Run ORBIT

Install Node.js 22 or newer, then run from this repository's root:

```sh
npm start
```

Open [localhost:4173](http://localhost:4173/). No package installation or build step is required.

Run the existing calculation tests:

```sh
npm test
```
